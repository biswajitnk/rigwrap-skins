# Rigwrap Skins — Official Public CDN

Public over-the-air (OTA) content delivery repository for [Rigwrap](https://rigwrap.app) — the companion utility and livery customizer for Truckers of Europe 3 (TOE3).

## Directory Structure
- `previews/`: High-resolution square showroom card previews for Garage, Viewer, and Gallery.
- `textures/`: Full UV texture map PNGs ready for export to Truckers of Europe 3.

## CDN URL Formats

### 1. jsDelivr Global Edge CDN (Recommended)
Fast edge caching with zero bandwidth limits powered by Cloudflare:
- **Preview**: `https://cdn.jsdelivr.net/gh/biswajitnk/rigwrap-skins@main/previews/<filename>.png`
- **Texture**: `https://cdn.jsdelivr.net/gh/biswajitnk/rigwrap-skins@main/textures/<filename>.png`

### 2. GitHub Raw CDN
Direct GitHub CDN fallback:
- **Preview**: `https://raw.githubusercontent.com/biswajitnk/rigwrap-skins/main/previews/<filename>.png`
- **Texture**: `https://raw.githubusercontent.com/biswajitnk/rigwrap-skins/main/textures/<filename>.png`
